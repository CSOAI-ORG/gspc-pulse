# GAMES — the measurement-instrument arcade (lane ↔ council-OS bridge)

The council's games (council-os/GAMES_SLATE.md, M4) are not gamified
marketing — **each game IS a data-collection instrument wearing a game skin**:
deterministic rulers only, gold labels, signed turns, honest UNMEASURED
states, two firewalls (measurement rails; outcomes analysed, never trained
into a champion).

## What this lane feeds each slot

| Slot | Game | The lane provides |

## H.I.M. and pets-to-pals

The H.I.M. view (Sentinel H.I.M. tab, council-OS Ask tab, GSPC-analyst
Modelfile) is the same council state explained conversationally. The "Pal"
is a presentation layer over that shared state — it can say "the care axis
is the fleet's weakest, here is the proof" — never a second permission
system. Voice/embodiment: presentation only; qualified separately per host.

## Round trips

Game play → signed labels (OMS/Sigil scope) → lane claims ledger → BFT vote
if doctrine requires → daily findings. Player data is never trained into a
champion model (firewall 2); it becomes **evidence**, which is IP, which is
value — the compounding loop.
